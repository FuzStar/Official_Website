# 内容怎么改

网站上的每一个字、每一条链接、每一个人名都在这 `content/` 目录里，页面本身不含任何内容。
改完文件提交并推送，网站会在几分钟内自动更新，不需要懂代码。

**共通的三条规矩**

- 只改冒号后面引号里的内容，不要动开头的缩进和 `-` 号，缩进错了网站会构建失败。
- 字段用不到就留空 `""`，页面上会自动不显示那一行，不要删掉字段名。
- yaml 文件里以 `#` 开头的整段都只是示例，不会被网站读取。要加内容，先把示例上面的 `#` 去掉，再改。

## 加一条公告

在 `notice/` 目录里新建一个 `.md` 文件，文件名用英文或数字，比如 `2026-10-05-halloween.md`。

文件开头两行 `---` 之间是配置，下面才是正文：

```
---
title: 公告标题
date: 2026-10-05
type: notice
pinned: false
---

正文写在这里，支持 Markdown。
```

- `type: notice` 是短公告，列表页直接把正文显示出来，读者不用点进去。
- `type: article` 是长文，列表页只显示摘要，点进去看全文。用这个要多写一个 `summary:` 字段，那是列表页显示的那句话。
- `pinned: true` 会置顶，最多建议置顶一条。
- `date` 只影响排序，写 `YYYY-MM-DD` 格式。

插图片：把图片放进 `public/notice/` 目录，正文里写 `![说明](/notice/图片名.png)`。

改标题不改文件名，网址不会变。删文件就等于删公告。

## 加一个工作人员

打开 `members.yaml`，照着已有的一段复制出来改内容。必填 `name`，其他都能留空。

头像有两种填法：把图片放进 `public/avatars/` 目录、字段写 `/avatars/文件名`；
或者 `avatar` 留空、只填 `qq`，网站就取那个 QQ 号当前的头像（对方换头像，页面跟着变）。

图片先裁成正方形、边长压到 256 左右再放进来。卡片上头像只有 56px，用手机原图那种
一两千像素的，白白让访客多下几百 KB。

`links` 是联系方式列表，展开写：

```
  links:
    - label: GitHub
      url: https://github.com/xxx
      icon: simple-icons:github
    - label: Discord
      value: "@用户名"
      icon: simple-icons:discord
```

有网址的填 `url`，点一下就跳过去；只有账号、没有网址的（比如 Discord 用户名）填 `value`，
卡片上会显示成不可点的样子。`icon` 可以不写，不写就只显示文字。列表顺序就是页面上的显示顺序。

一个人都没填的时候，工作人员页会显示一句"名单还没公开"，不会出现空卡片。

## 加一个友链

打开 `friends.yaml`，示例同样是注释状态，取消注释后复制多份改内容。logo 放进 `public/logos/`。

合作方式的说明文字不在这里。`site.yaml` 的 `collaboration` 是"友链与合作"页底部的完整说明（按 markdown 写），`collaborationLead` 是首页那条横幅上的一句话摘要（纯文本）。

## 改关于我们页

打开 `about.yaml`。`lead` 是页头标题下面那句导语，`sections` 是下面的板块列表，每块有 `title` 和 `body`。加板块就复制一段 `sections` 改；哪块暂时不想放就整段删掉，页面跟着少一块。

`body` 按 markdown 写，列表（`- 一项`）、加粗（`**字**`）、小标题（`#### 标题`）都认。

## 改游戏服页

`minecraft.yaml` 管着"游戏服"那一页。

- `name` 是服务器名，`lead` 是页头标题下面那句话。
- `status.java` 填玩家实际连的那个域名，页面顶上就会挂一个实时在线状态。填域名就行，**不要带端口**，两个查询服务都会自己解析 SRV。这个字段留空则整块不显示。
- `addresses` 是连接地址卡片，一张一条。`platform` 决定图标，只能写 `java` 或 `bedrock`；`port` 留空表示走 SRV，玩家不用填端口，填了页面会单独列出来配一个复制按钮。
- `access` 是"怎么进来"的几条路径，每条一个 `title` 和一个 `body`。
- `about` 是"这服在玩什么"，`rules` 是服务器规矩，`penalty` 是处罚对照表。
- `joinNote` 是页面底部引导进群那句话，纯文本。

`about`、`rules`、`penalty`、`access[].body` 按 markdown 写。除了列表、加粗、小标题，这几段还认表格和行内代码：

```
| 情况 | 处理 |
| --- | --- |
| 刷屏 | 先提醒，不听就禁言 |
```

游戏指令这类要玩家照抄的内容，用反引号包起来会显示成等宽底纹，像 `/login 密码` 这样。规矩那类要带序号的，用 `1.` 开头写，页面上会自动排成 1、2、3。

基岩端的在线状态查不了（海外探测节点连不上国内 UDP 端口），所以只写连接方式，不挂状态徽章。哪天服务器换到能被外部探到的线路上，跟我说一声，我再加上基岩端的查询。

## 改教程页

`minecraft-guide.yaml` 管着 `/minecraft/guide`，就是从游戏服页点进去的那页指令速查。

页面按"块"组织，一块在页面上是一节，顶上那排跳转按钮也是照 `sections` 生成的。

- `lead` 是页头标题下面那句话。
- `sections` 是块列表，想加一块就整段复制一份改。一块都不想要时把 `sections` 整段注释掉，页面自动隐藏目录和正文。
  - `id` 是锚点，别的地方可以用 `/minecraft/guide#residence` 直接跳到这块，起好之后别再改。
  - `title` 是块标题，`lead` 是块开头那句话。
  - `groups` 用来把指令分组，每组一个 `title`；只有一组时可以不写 `title`。
  - `entries` 是一条条指令：`cmd` 是指令原文，页面上等宽显示并配一个复制按钮，留空就是一条没有指令的纯提示；`desc` 是说明，只支持行内写法，也就是 `**加粗**` 和反引号包起来的代码。**这里写 `-` 列表或 `####` 标题不会生效**，会原样显示出来。
  - `note` 是块尾的补充说明，按正常 markdown 整段渲染，能写列表、能分行。

每块左边那个图标跟着 `id` 走：`residence`、`teleport`、`economy`、`rewards` 各配了一个，写了别的 `id` 会落到一本打开的书上。想换图标跟开发说——图标是打进包里的，得同步改 `nuxt.config.ts` 里的白名单，光改 yaml 页面上会空一块。

## 改站点信息

`site.yaml` 里是站点名、域名、联系邮箱、社区群链接、招募岗位、备案号。

- `org.badge` 是首页标题上方那个小标签；`org.tagline` 是首页大标题下面那句话；`org.intro` 是首页"关于我们"那一段，留空整段不显示。
- `groups` 是社区群，首页和加入我们页都按这份列表渲染。`platform` 决定卡片上的图标，可选 `qq` / `qqchannel` / `discord` / `telegram`；`name` 是群名；`handle` 填群号或频道号（页面上会做成点击复制），Discord 这类没有号的留空；`note` 是一句话说明。
- `roles` 是招募岗位，加入我们页按这个列表渲染。它是**两级**的：一个部门下面挂若干下挂部门。

```
roles:
  - title: 开发部          # 部门名，纯文本
    slots: 招 4 人         # 人数徽章，留空不显示
    note: ""               # 部门名旁边的小字说明，纯文本
    duty: 负责什么          # markdown
    requirement: 有什么要求  # markdown
    groups:                # 下挂部门
      - title: 后端开发
        slots: ""
        note: ""
        duty: ""
        requirement: 要求原文
```

  加部门就复制一整段改，加下挂部门就复制一份 `groups` 里的那段。下挂部门的字段和部门完全一样，用不到的都留空，那一栏自动不显示。`note` 可以拿来解释名字，比如方块运营那条写 `Minecraft 社区服运营组`。
- `recruitNote` 是岗位列表上方的招募说明，留空不显示。
- `joinLead` 是加入我们页开头那句话。这页底下有两条路（进社群、进工作团队），用它交代清楚，别让只想进群的人以为下面的门槛跟自己有关。

### 哪些字段能写 markdown

`recruitNote`、`roles[].duty`、`roles[].requirement`、`collaboration`，以及每个下挂部门的 `duty`、`requirement`，支持三种写法：

```
- 列表项        页面上的方点列表
#### 小标题      分组标题
**加粗**        强调
```

部门和下挂部门已经是两级了，别再靠 `#### 小标题` 在正文里分组，那会把目录结构藏在文字里。

多行内容用 `|-` 开头的块写，每一行缩进保持一致、比字段名多两格：

```
    requirement: |-
      #### 后端开发

      - 第一条
      - 第二条
```

其余字段（`org.*`、`groups[].*`、`roles[].title`、`roles[].slots`、`roles[].note`、下挂部门的 `title` / `slots` / `note`）是纯文本，写什么显示什么——
敲进去的星号、井号会原样出现在页面上，不会被当成语法。

`icp` 是备案号，没下来之前留空，页脚就不显示备案信息。

## 彩蛋

`eggs.yaml` 里是藏在站点各处的小东西，给愿意乱点、乱按、翻源码的人准备，不用宣传。

| 字段 | 怎么触发 |
| --- | --- |
| `konami.text` | 依次按 ↑ ↑ ↓ ↓ ← → ← → B A，屏幕落一阵星星 |
| `typing` | 连着敲出 `keys` 里的词（现为 `fuzz`）；在输入框里打字不算 |
| `paw.text` | 网址后面加 `?paw=1`，全站光标变爪印 |
| `night.text` | 凌晨 0 点到 5 点之间打开页面，页脚多一句 |
| `year.text` | 页脚版权那行的年份连点 5 下 |
| `lost.text` | "这一页走丢了"那个页面上，连点星星 5 下 |
| `console` | 打开浏览器控制台（F12） |
| `comment` | 右键"查看网页源代码" |

**把某条的 `text` 清空就等于关掉它**，页面对这个动作不再有任何反应，不用改代码。
`console`、`comment` 这两条没有 `text`，直接清空字段值即可。触发方式本身写在代码里
（`app/components/site/EasterEggs.vue`、页脚和 `app/error.vue`），要换玩法得改那几处。
